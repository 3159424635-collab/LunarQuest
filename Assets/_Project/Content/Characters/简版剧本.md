# 月球计划简版剧本

玩家以第一人称完成从地面发射到月面采样再返回的体验。对话保持简短，把时间留给观察、行走和驾驶。体验目标为 15 至 20 分钟，月面科考约 8 至 10 分钟。以下姓名、台词和互动细节为创作草案；主流程依据提供的设计文档。

## 序幕 地球发射场

场景为发射场指挥中心。地面飞控林岚位于可见位置，以 wave 招呼。交互提示出现后，玩家按 E 对话。

林岚：“欢迎加入任务。我是飞控林岚。先熟悉一下操作：用 WASD 移动，移动鼠标观察四周。”

玩家完成移动与观察后，林岚示意任务终端。

林岚：“靠近发光的交互点，按 E 确认。准备好后，到观景平台集合。”

玩家确认终端并抵达平台后，林岚通过无线电通报。

林岚：“发射准备完成。看向发射塔，我们即将出发。”

画面接入原流程的十秒倒计时与发射演出。NPC 不再拦截玩家；在倒计时开始前完成教学。

## 第一幕 绕月

玩家在指令舱内观察舷窗。左右方向键视角提示只出现一次。舱外景观与数据 HUD 由场景系统提供。

林岚：“地球正在身后缩小。用左右方向键微调视角，看看我们的目的地。”

进入着陆段前，飞控通报。

林岚：“已进入环月轨道，准备着陆。请留意下降速度和着陆腿应力。”

## 第二幕 着陆

画面进入简易着陆交互。此处以现有设计的推力、下降速度和应力反馈为主，台词只提供提示。

林岚：“用上下方向键调整反推，把速度和应力保持在安全范围。”

失败时停留在着陆段重试，不重复播放整个绕月演出。

林岚：“这次下降没有进入安全范围。重新调整推力，再试一次。”

成功落月后发动机熄火，短暂停顿，再接无线电。

林岚：“着陆确认。欢迎来到月球，广寒站正在等你。”

## 第三幕 月面科考

### 出舱与前往基地

玩家从着陆点出舱，完成低重力移动教学，再前往月球车。维护员陈越通过无线电联系，不要求玩家先找到一个额外的地面 NPC。

陈越：“这里是广寒站机务。月面移动先放慢一点，熟悉落地节奏，再去月球车旁集合。”

教学完成后，陈越提示导航。

陈越：“车辆已就绪。跟着导航到广寒站，任务协调员会为你安排采样工作。”

### 广寒站接任务

周航在任务区查看平板。玩家靠近时抬头，按 E 开始交互。

周航：“欢迎来到广寒站。我是周航。请到 3 号陨石坑勘测点采集三份月壤样本，再交给站内的许青。”

玩家确认接取后，任务 HUD 显示目的地和样本数 0/3。

周航：“勘测点已标在导航上。到达后，靠近采样点并按住 E。留意岩石和地形起伏。”

已接任务但样本不足时再次交互：

周航：“任务仍在进行。请继续前往标记的采样点，集齐三份后回站。”

样本已经集齐时再次交互：

周航：“三份样本已经齐了。请送到样本接收区，许青在那里等你。”

### 陨石坑采样

玩家沿小地图驾驶到 3 号陨石坑。每个采样点只可成功记录一次；按住 E 时播放 sample 循环和进度条。松开按键则停止演出，是否保留进度由游戏实现统一决定。

陈越：“勘测点到了。停稳后下车，靠近标记位置，按住 E 完成采样。”

第一份采样成功，玩家：“第一份样本已封存。”

第二份采样成功，玩家：“第二份样本已封存。”

第三份采样成功，玩家：“三份样本齐了，返回广寒站。”

重复交互已采集点时，字幕提示：“此点已完成采样，请前往其他标记。”不增加计数。

### 返回与交付

许青在样本接收区等待。玩家不足三份时交互，保持任务进行中，不消耗样本。

许青：“还差一些样本。请按导航补齐三份，我们再一起检查。”

玩家集齐三份后交互：

许青：“三份样本都到了。辛苦了，我来接收并登记。”

许青播放 receive，玩家播放 interact；样本交付事务只执行一次。完成后切回 idle。

许青：“样本已接收。接下来可以去科普展示厅，看看探月任务如何把这些线索带回地球。”

交付完成后再次对话：

许青：“你的样本已经登记好了。展示厅就在前方，随时可以参观。”

### 科普展示厅

玩家进入展示厅并与展示装置交互。视频素材与授权由团队另行准备，不在角色包中附带。

许青：“每一次观察和采样，都在帮助我们认识月球。请看展示，了解探月任务的更多故事。”

玩家完成展示交互后，返回目标激活。

周航：“本次科考完成。请按导航返回，准备回家。”

## 第四幕 返回

沿用原流程的交会对接、再入、开伞与着陆演出。飞控只在关键节点讲话。

林岚：“返航流程已确认。带着今天的收获，我们回家。”

地面着陆后显示结算。

林岚：“欢迎回到地球。任务完成，感谢你的参与。”

结算统计使用实际游戏数据。探月时间线中的年份、任务名称和数值应在最终接入时单独核实，本角色草案不重复抄录这些科普数据。

## 任务状态约定

| 任务 ID | 完成条件 | 主要交互对象 |
| --- | --- | --- |
| T00_launch | 移动、观察、E 教学完成并触发发射 | ground_flight_controller |
| T10_lunar_orbit | 绕月演出完成，切入着陆段 | ground_flight_controller 无线电 |
| T20_landing | 着陆成功；失败只重试本段 | ground_flight_controller 无线电 |
| T30_eva | 完成出舱移动教学并抵达广寒站 | maintenance_technician 无线电 |
| T31_base_briefing | 在基地确认接取采样任务 | base_coordinator |
| T32_sample_collection | 在三个不同采样点分别成功采样，共三份 | player_astronaut |
| T33_sample_delivery | 向科学家成功交付一次，记录交付标记 | lunar_scientist |
| T34_exhibit | 完成展示装置交互 | lunar_scientist 与展示装置 |
| T40_return | 返回演出结束并进入结算 | ground_flight_controller 无线电 |

机器可读的具体条件、台词 ID 和事件效果见 `data/dialogue.json`。该 JSON 是接入数据约定，需由游戏端读取与执行；文件本身不包含任务系统。
