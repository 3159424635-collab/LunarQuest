# 月球计划角色与动作草案

本包提供第一人称月球体验所需的可用角色草模、基础动作与台词接入数据，供团队评审和原型搭建。当前内容是可用草模，尚非最终精模，也未接入游戏端。角色职责和任务流程依据提供的流程文档整理；姓名、外观、配色和台词为本次创作草案。人物均为虚构角色，不对应真实航天员或飞控人员。

## 角色分工

| 角色 ID | 显示名称 | 出现场景 | 作用 | 当前模型外观 |
| --- | --- | --- | --- | --- |
| player_astronaut | 玩家宇航员 | 全程 | 第一人称观察、交互、采样；完整身体供影子、镜头和后续扩展使用 | 白色与橘色舱外服，金色面罩，生命保障背包 |
| ground_flight_controller | 林岚 · 地面飞控 | 发射场；后续无线电 | 移动与交互教学、发射提示、绕月与返回通报 | 蓝色工装，耳机与平板 |
| base_coordinator | 周航 · 基地任务协调员 | 广寒站任务区 | 发放 3 号陨石坑采样任务，提示当前进度 | 橘色工装与平板 |
| lunar_scientist | 许青 · 月球科学家 | 广寒站样本接收区 | 接收三份样本，触发科普厅参观 | 白色外套配青色，样本罐 |
| maintenance_technician | 陈越 · 设备维护员 | 车库或气闸附近 | 提供月球车与出舱提示，补充基地生活感 | 深蓝色与黄色工作服，工具；作为非必需的环境 NPC |

五个完整角色各有 20 根骨骼，第一人称双臂资产有 7 根骨骼。模型采用刚性分段权重，关节处是分段草模表现；没有面部骨或手指骨，手指仅有几何形状，不能独立弯曲。后续若需柔性衣物变形、精细手势或口型，需要继续制作。

## 模型文件与场景

主文件为 `guanghan_characters.blend`，包含 `01_CHARACTER_LINEUP` 角色排列场景与 `02_FIRST_PERSON_REFERENCE` 第一人称参考场景。参考环境仅用于查看比例、镜头和姿态，不包含在角色 GLB 中。各角色 GLB 与独立第一人称双臂 GLB 用于游戏引擎导入。

动作合计为 45 个片段：4 个 NPC 各 8 个，共 32 个；玩家完整身体 9 个；第一人称双臂 4 个。动画中的角色演出不能替代游戏中的移动、交互或任务逻辑。

## 主视角资产

第一人称双臂以 `first_person_arms` 独立资产提供，含 idle、walk、interact、sample 四个动作；玩家完整身体含 NPC 的八个共用动作及 interact，共九个。常规第一人称镜头应由游戏端隐藏完整身体的头部和胸前遮挡物；需要脚部影像时再显示完整身体。身体、双臂、道具挂点与相机归属仍需接入配置，避免双套手臂同时显示。

| 动作 ID | 用途 | 播放方式 | GLB 时长 |
| --- | --- | --- | --- |
| idle | 静止与等待 | 循环 | 49 帧采样，2 秒 |
| walk | 步行，双臂小幅交替摆动 | 循环、原地；位移由角色控制器处理 | 49 帧采样，2 秒 |
| interact | 按 E 交互时前伸并收回 | 单次 | 73 帧采样，3 秒 |
| sample | 按住 E 的采样演出 | 循环；计数由游戏逻辑触发 | 73 帧采样，3 秒 |

月面跳跃与低重力位移由角色控制器实现。流程文档中的“6 倍跳跃高度”是体验设计参数，不通过把 walk 动画拉长来模拟。采样动作只提供演出，不直接增加样本数。

## NPC 共用动作

每个 NPC 均包含以下八个动作。

| 动作 ID | GLB 时长 | 循环 | 对应行为 |
| --- | --- | --- | --- |
| idle | 49 帧采样，2 秒 | 是 | 站立、轻微呼吸 |
| walk | 49 帧采样，2 秒 | 是 | 原地步行，移动路径由游戏逻辑控制 |
| wave | 73 帧采样，3 秒 | 否 | 招呼玩家或指示 NPC 可交互 |
| talk | 73 帧采样，3 秒 | 是 | 小幅手势与头部朝向，台词结束后切回 idle |
| point | 73 帧采样，3 秒 | 否 | 指向任务地图、车辆、出舱方向或展厅 |
| tablet | 73 帧采样，3 秒 | 是 | 查看任务终端与记录数据 |
| sample | 73 帧采样，3 秒 | 是 | 演示采样、检查工具或整理样本 |
| receive | 73 帧采样，3 秒 | 否 | 双手前伸接收样本，然后回到待机 |

GLB 动画以 24 fps 导出。49 个采样帧包含两个端点，覆盖 48 个帧间隔，即 2 秒；73 个采样帧覆盖 72 个帧间隔，即 3 秒。idle、walk、talk、tablet、sample 按循环设计，首尾回位；wave、point、receive、interact 为单次动作。引擎导入后仍需按此设置循环播放。首版使用手势配字幕，无录音、口型或面部表情资产。不得将 talk 的循环时长视为台词播放时长。

## 动画与交互约定

- 动作统一使用上述小写 ID；若导出时增加角色前缀，在资产清单中记录映射。
- 非循环动作结束后由游戏端切回 idle；talk 和 tablet 可在交互结束时平滑退出。
- walk 与 sample 默认采用原地动作。禁止将骨架的前进位移再叠加到角色控制器移动上。
- NPC 的看向玩家、交互距离、路径寻路、碰撞体、样本道具传递与台词字幕均由游戏端控制。
- 动作与台词事件可以共用，但奖励、样本消耗和关卡跳转必须由任务状态控制，避免重复交互重复发奖。

## 团队接入检查

1. 确认角色单位、身高比例、前向和骨架方向；在地面平面上检查脚底。
2. 用 idle、walk、interact 或 receive 检查肩肘腕的连接与穿插。
3. 逐一导入角色和动作，确认角色 ID、动作 ID 与 `data/dialogue.json` 一致。
4. 检查第一人称相机近裁剪、手部遮挡与工具挂点。
5. 在游戏中验证样本不足、重复接任务、重复交付与完成后的对话。

当前交付可用于角色草模评审、动画预览和游戏导入试接。最终精模、柔性蒙皮、面部与手指骨骼，以及游戏控制器、任务系统、碰撞和配音尚未完成或接入。
