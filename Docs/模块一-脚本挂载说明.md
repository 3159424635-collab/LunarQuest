# 模块一 · 白盒原型脚本挂载说明

> 目标：W2 里程碑——**在灰盒月面上，能走、能跳、能开车跑圈、小地图能转、能按 E 采样**。
> 前提：Unity 2022.3 LTS + URP 工程已建好（建法见 README 与组内说明）。所有脚本都在 `LunarQuest` 命名空间下。

## 脚本清单与课程要求对照

| 脚本 | 位置 | 功能 | 对应课程要求 |
|---|---|---|---|
| `FirstPersonController` | Scripts/Player | WASD 行走、鼠标视角、可调重力跳跃 | 宇航员第一视角、月面行走 |
| `PlayerInteractor` | Scripts/Player | 视线射线检测 + E 键交互 + 提示事件 | 交互体验 |
| `RoverController` | Scripts/Vehicle | ←→ 转向、↑↓ 油门刹车、Shift 加速、空格手刹 | **方向键视线/速度控制（硬指标）** |
| `RoverCamera` | Scripts/Vehicle | 追尾跟随 + 速度感 FOV | 越野飞车体验 |
| `MinimapController` | Scripts/UI | 正交俯拍跟随、M 键切换远近、坐标换算 | **小地图（硬指标）** |
| `InteractableBase` | Scripts/Misc | 所有交互物的基类 | — |
| `SampleRock` | Scripts/Misc | 测试用样本：按 E 采集 | 采样任务原型 |

方向键无需配置：Unity 默认 Input Manager 的 Horizontal/Vertical 轴已同时绑定 WASD 与方向键。

## 一、白盒测试场景搭建（约 15 分钟）

### 1. 地面
没拿到模块二的灰盒地形前，先自建临时地面：GameObject → 3D Object → Plane，Scale 设为 (50, 1, 50)（即 500×500 米），再摆放几个旋转过的 Cube 作为斜坡和岩石。

### 2. 步行玩家
1. 新建空物体，命名 `Player`，位置 (0, 1, 0)
2. Add Component → **Character Controller**（Height 1.8，Center Y 0）
3. Add Component → **First Person Controller**、**Player Interactor**
4. 把场景里的 Main Camera 拖成 `Player` 的子物体，Position 设 (0, 0.6, 0)、Rotation 归零

### 3. 月球车
1. 新建 Cube，命名 `Rover`，Scale (2.2, 0.9, 3)，放在玩家旁边、离地 1 米
2. Add Component → **Rover Controller**（Rigidbody 会自动添加，质量脚本会自动设为 220）
3. 新建 Camera，命名 `RoverCam`，Add Component → **Rover Camera**，把 `Rover` 拖进 Target
4. **测车时**：禁用 Player 物体、启用 RoverCam；**测步行时**反过来（上下车切换脚本是下一批交付）

### 4. 小地图
1. 新建 Camera，命名 `MinimapCam`，Add Component → **Minimap Controller**，Target 拖当前在测的对象（Player 或 Rover）
2. Project 窗口右键 → Create → **Render Texture**，命名 `RT_Minimap`，尺寸 512×512
3. 把 `RT_Minimap` 拖到 MinimapCam 的 **Output Texture**（Target Texture）槽
4. 新建 UI → **Raw Image**，Texture 设为 `RT_Minimap`，锚到屏幕右上角，宽高 220×220
5. 圆形外观：给 RawImage 的父物体加 **Mask** + 圆形 Image（这一步属于界面样式，模块四正式拼 HUD 时会替换）
6. 运行后按 **M** 切换远近两档视野

### 5. 交互测试
新建 Cube（缩小一点当岩石）→ Add Component → **Sample Rock**。运行，走到 3 米内看向它，按 E，Console 出现采集日志且岩石消失即成功。

## 二、验收清单（逐条跑通 = W2 达标）

- [ ] 步行：WASD 移动流畅，鼠标视角稳定，俯仰角度限制正常
- [ ] 月面跳跃：空格跳起后滞空明显延长；将 Gravity Scale 改为 1 再跳，可对比地球与月面的差异
- [ ] 驾驶：↑ 起步加速有力，↓ 先刹车、停稳后倒车，←→ 转向
- [ ] 越野感：低速转向灵活，高速转向明显变钝
- [ ] Shift 加速：最高速度明显提升，视野同步拉宽
- [ ] 空格手刹：高速转弯时按住，车尾甩出产生漂移
- [ ] 稳定性：驶上斜坡、撞击岩石时不侧翻、不弹飞
- [ ] 小地图：跟随移动，M 键切换远近
- [ ] 交互：看向岩石按 E 能采集

## 三、手感调参速查

| 现象 | 调整参数 | 调整方向 |
|---|---|---|
| 起步加速不足 / 过猛 | RoverController → Motor Force | 增大 / 减小 |
| 转向过于灵敏 / 迟钝 | Steer Speed | 减小 / 增大 |
| 高速转向依然过急 | Min Steer Factor | 减小（如 0.25） |
| 抓地不足，车身侧滑明显 | Normal Grip | 增大 |
| 手刹漂移效果不明显 | Handbrake Grip | 减小（如 1.5） |
| 爬坡时车身腾空 | Down Force | 增大 |
| 月面跳跃滞空感不足 | FirstPersonController → Gravity Scale / Jump Height | 减小重力 / 增大跳跃高度 |
| 鼠标视角转速过快 / 过慢 | Mouse Sensitivity | 减小 / 增大 |

## 四、第二批脚本（已交付）

| 脚本 | 位置 | 功能 |
|---|---|---|
| `VehicleEnterExit` | Scripts/Vehicle | 上下车切换：步行靠近月球车 3.5 米内按 F 上车，车内按 F 下车；自动启停控制器与相机 |
| `HUDController` | Scripts/UI | HUD 逻辑层：交互提示、车速、任务提示；白盒阶段自带左上角调试显示 |
| `MinimapUI` | Scripts/UI | 小地图图标层：玩家箭头随朝向旋转，任务点按世界坐标定位并钳制在地图边缘 |

### 上下车挂载
1. 月球车物体上 Add Component → **Vehicle Enter Exit**，`Player` 字段拖玩家根物体，`Rover Camera` 字段拖场景中挂 RoverCamera 的相机物体
2. 运行：步行靠近车按 F 上车，再按 F 下车（下车点在车身左侧，可用 Exit Offset 调整）
3. 注意：脚本启动时会自动关闭车辆控制与车辆相机，无需手动处理初始状态

### HUD 挂载
场景新建空物体命名 `HUD`，Add Component → **HUD Controller**。运行后左上角显示速度与交互提示（白盒调试 HUD）；模块四交付正式界面后，把对应 UGUI Text 拖入字段、关闭 Show Debug Hud 即可切换。

### 小地图图标挂载
1. 在小地图底图 RawImage 下新建两个 Image 子物体：`Arrow`（三角形，代表玩家）与 `QuestMarker`（任务点）
2. 场景新建空物体挂 **Minimap UI**：Minimap 拖小地图相机、Map Image 拖底图 RawImage、Player Arrow / Quest Marker 拖两个 Image
3. 测试：把场景中任意物体拖进 Quest Target，运行后图标应随其世界位置移动，超出范围时停在地图边缘
