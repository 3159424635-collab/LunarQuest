# 模型交付规范（模块二 · 场景与美术）

> 这份规范保证美术资产拖进 Unity 后，程序脚本不用跟着改。白盒和正式模型都按这个来，第一次交付前花两分钟对照一遍。

## 一、三条死规定（不符合会直接导致程序出问题）

| 规定 | 要求 | 不遵守的后果 |
|---|---|---|
| **比例** | 1 单位 = 1 米。宇航员约 1.8 米高，月球车约 3 米长 | 速度、重力、跳跃全部失真 |
| **原点（Pivot）** | 放在模型**底部中心**（落地的那个点） | 摆进场景会悬空或陷地，车辆旋转中心错位 |
| **朝向** | 模型**正面朝 +Z 轴**，上方朝 +Y | 月球车会"倒着开"或侧着开 |

## 二、命名

| 类型 | 前缀 | 示例 |
|---|---|---|
| 静态模型 | `SM_` | `SM_Rover`、`SM_Habitat_01`、`SM_Rock_A` |
| 材质 | `M_` | `M_Rover_Body`、`M_MoonGround` |
| 贴图 | `T_` + 用途后缀 | `T_Rover_Albedo`、`T_Rover_Normal` |

## 三、碰撞

- 地形、建筑、大石头等**静态物体必须带碰撞体**（月球车靠它们才能跑和撞）
- 优先用简单碰撞体（Box / Capsule），复杂形状用 Mesh Collider；小碎石可以不加
- 月球车**不要自带碰撞体和 Rigidbody**，程序会统一处理

## 四、面数与贴图预算（低模优先，风格统一比精度重要）

| 资产 | 面数上限（三角面） | 贴图 |
|---|---|---|
| 月球车 | 8,000 | 最大 2K |
| 基地单个舱段 | 5,000 | 最大 2K |
| 着陆器 | 6,000 | 最大 2K |
| 石头 / 道具 | 500 | 512 即可 |

## 五、Blender 导出 FBX 设置

- 单位：Scale 1.0，Apply Scalings 选 **FBX Units Scale**
- 轴向：Forward 选 **-Z Forward**，Up 选 **Y Up**（导入 Unity 后正面即朝 +Z）
- 勾选 **Apply Transform**；不要勾 Embed Textures（贴图单独放 `Art/Textures`）

## 六、存放位置

- 模型 → `Assets/_Project/Art/Models/`
- 材质 → `Assets/_Project/Art/Materials/`
- 贴图 → `Assets/_Project/Art/Textures/`
- 搭好的场景 → `Assets/_Project/Scenes/`（S1~S5 命名：`S1_LaunchSite`、`S4_MoonBase` 等）
