# 教程：白盒月面地形（第一版）

本教程面向零基础成员，目标是在 1 至 2 小时内完成一张 500×500 米的灰盒月面地形，供驾驶与采样交互先行开发。第一版不要求任何美术效果：不上贴图、不做颜色、不建精细模型，只要求尺寸、起伏和位置正确。统一工程建立后，本地形将在工程内重建提交，届时熟练成员约 1 小时即可完成。

## 交付物与验收标准

| 项目 | 要求 | 用途 |
|---|---|---|
| 可行驶月面 | 500×500 米，边缘有阻挡 | 月球车驾驶 |
| 3 号陨石坑 | 直径约 60 米、深 6–8 米，坑内分布 3 个采样点标记 | 采样任务主区域 |
| 另外两个陨石坑 | 直径 40–80 米不等，深 4–8 米 | 视觉节奏与探索 |
| 乱石区 | 20–30 块带碰撞的岩石，集中分布在一片区域 | 驾驶障碍 |
| 基地平整区 | 约 100×100 米的平坦区域 | 广寒站建筑、车库 |
| 着陆区 | 约 60×60 米的平坦区域 | 着陆与返回演出 |

风格说明：本项目角色草稿已确定为低多边形方块风格，地形第一阶段无需精细雕刻，起伏自然、比例正确即可。后续整体风格统一由贴图与岩石模型阶段解决。

## 第一步：新建临时工程

统一工程尚未建立，先自建一个练习工程：

1. 打开 Unity Hub，新建项目，模板选择 **3D (URP)**，Unity 版本 **2022.3.62f1**，命名 `TerrainPractice`。
2. 保存初始场景为 `Assets/Scenes/WhiteboxTerrain.unity`。

## 第二步：创建地形

1. Hierarchy 窗口右键 → **3D Object → Terrain**。
2. 选中 Terrain，Inspector 中点击最右侧的齿轮（Terrain Settings）。
3. 在 Mesh Resolution 处设置：Terrain Width = **500**，Terrain Length = **500**，Terrain Height = **100**。

Terrain 自带 TerrainCollider，无需手动添加碰撞。

## 第三步：挖三个陨石坑

1. 选中 Terrain，Inspector 第一个标签 **Paint Terrain**，工具选 **Raise or Lower Terrain**。
2. 笔刷大小设 **60**（即 3 号坑直径），笔刷强度设 **0.2**。
3. **按住 Ctrl 并连点坑心**约 10 次，每点几次就转视角观察深度；目标坑深 6–8 米（可用坑边一块 Cube 立着当 8 米参照）。
4. 换 **Smooth Terrain** 工具，强度 0.3，在坑沿抹两圈，消除锯齿。
5. 用同样方法再挖两个坑：一个直径约 40、深约 4；一个直径约 80、深约 6。三个坑彼此相距 100 米以上，且都不在基地平整区范围内。

如刷坏需要重来：Terrain Settings 中有重置高度图选项（Reset heightmap），可整体清平重刷。

## 第四步：平整基地区与着陆区

1. Paint Terrain → **Flatten Terrain**，高度值先设为基地所在位置的大致高度。
2. 在预定基地位置（建议地图中央偏北）连续点击并拖动，铺出约 100×100 米的平整区。
3. 同法在距基地约 150 米处铺出 60×60 米着陆区。

## 第五步：摆放乱石区

1. Hierarchy 右键 → **3D Object → Cube**，复制 20–30 个。
2. 随机缩放（边长 0.5–3 米）、随机旋转，集中摆放在地图东侧一片约 80×80 米的区域内。
3. 逐一命名 `Rock_01`、`Rock_02`……（Cube 自带碰撞，无需改动）。

## 第六步：放置采样点与出生点

1. Hierarchy 右键 → **Create Empty**，分别命名 `SamplePoint_A`、`SamplePoint_B`、`SamplePoint_C`，放进 3 号坑内三个不同位置（彼此相距 10 米以上）。
2. 再建一个空物体命名 `PlayerSpawn`，放在基地平整区中央。

这两个名称是交互脚本的挂载点，请勿使用其他命名。

## 第七步：自测

1. 建一个 Cube 置于 3 号坑上空 30 米，挂上 Rigidbody（默认设置），进入运行模式：它应落到坑底且不穿入地面。
2. 从基地走到 3 号坑沿途无异常凹陷；乱石区可正常碰撞。
3. 自测通过后截图三张：地图全景、3 号坑近景、基地平整区。

## 提交方式

统一工程建立前：将三张截图发到群里，场景文件 `WhiteboxTerrain.unity` 一并发送或推送。
统一工程建立后：在本仓库 `Assets/_Project/Scenes/` 下按上述规格重建并提交，提交信息格式为 `模块二: 白盒月面地形第一版`。
