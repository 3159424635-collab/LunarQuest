# 《月征：绕·落·回》—— 探月工程沉浸式体验 项目方案书

> 虚拟现实设计课程设计 · 4人小组 · 版本 V1.1

---

## 一、项目概述

### 1.1 一句话概念
以中国探月工程"绕、落、回"三步走为背景，玩家扮演一名中国宇航员，从文昌发射场起飞，经历地月转移、绕月飞行、月面着陆，在月球基地完成科考任务后携带样本返回地球——一段约 15~20 分钟的教育娱乐并重的主线体验。

### 1.2 项目定位
- **类型**：第一人称沉浸式体验 + 载具驾驶 + 轻任务驱动
- **平台**：PC 为主体（Unity 播放器，键盘操作，无需 VR 头显，课程要求即为方向键控制）；另含手机端 AR 场景（AR Foundation），用于"虚实结合"的呈现
- **基调**：真实科普为骨（真实任务时间线、真实数据、真实影像），游戏体验为皮（低重力行走、月球车越野、任务积分）

### 1.3 课程设计要求覆盖表（自查用）

| 课程要求 | 本方案的落实 | 对应模块 |
|---|---|---|
| 小地图 | 月面段 HUD 圆形小地图（正交相机 + RenderTexture），显示玩家朝向、任务点、基地 | 模块一 |
| 方向键视线/速度控制 | 月球车：←→ 转向、↑↓ 油门刹车、Shift 加速、空格 手刹漂移 | 模块一 |
| 场景模型构建 | 发射场、运载火箭、指令舱、月球基地（3舱段）、月球车、月面地形（陨石坑/岩石/月尘） | 模块二 |
| NPC 角色 | 基地指挥官（发任务）、随行科学家（科普对话）、地面飞控（语音提示） | 模块一（逻辑）+ 模块三（人设与台词） |
| 虚实结合 | ① 场景内展览舱与展览台（微缩模型 + 介绍页面 + 二维码）② 手机扫描游戏画面中的二维码，AR 呈现对应拟真模型（AR Foundation）③ 真实素材贯穿：月面贴图用真实照片、HUD 嵌真实数据（嫦娥五号采样 1731g）、开场真实发射影像转场 | 模块一（AR 实现）+ 模块二（展览舱造景）+ 模块三（内容与数据） |
| 音效配乐 | 发射轰鸣、舱内无线电、月面环境音、BGM、UI 音 | 模块四 |
| 每人第12周汇报 | 四大模块各对应一份独立、可展示的产出（见第六节） | 全员 |
| 提交五件套 | PPT、Word 报告、Unity 工程、操作手册、演示视频 | 全员 |

## 二、体验流程设计（五幕结构）

总时长目标 15~20 分钟，其中第三幕（月面）占一半以上，是工作量与亮点重心。

### 序幕 · 蓄势（地球发射场，约 2 分钟）
- 玩法：第一人称步行，在发射场指挥中心走动，与**飞控 NPC** 对话完成教学（移动 WASD、交互 E、视角鼠标）。
- 演出：走出发射场观景平台，仰视运载火箭与发射塔架（"胖五"比例参考）；倒计时 10 秒，真实历史发射影像快剪转场 → 切入虚拟火箭升空，震屏 + 音量渐强。
- 目的：教学 + 情绪铺垫 + 展示地球场景美术。

### 第一幕 · 绕（地月转移与绕月轨道，约 2 分钟）
- 演出：指令舱内视角，舷窗外地球渐渐缩小、月球渐渐放大，日地月同框的"地出"景观。
- 轻交互：玩家可用 ←→ 微调舷窗摄像头视角观赏太空（满足"视线方向控制"的另一种体现）；HUD 显示真实数据（地月距离 38 万公里、飞行时长等）。
- 转折：飞控语音通报"进入环月轨道，准备着陆"。

### 第二幕 · 落（动力下降着陆，约 2 分钟）
- 玩法：简易着陆小游戏——↑↓ 控制反推推力，控制下降速度与水平漂移，着陆腿应力表在安全线内则着陆成功（失败重试，无惩罚）。
- 演出：月面越来越近，扬起月尘，发动机熄火瞬间静音 → 舱内掌声无线电。
- 目的：一个低成本但"可玩"的技能小游戏，让"落"字有参与感。

### 第三幕 · 月面科考（核心玩法，约 8~10 分钟）
登陆月球基地"广寒站"，这是全项目的重心，玩法循环：

> **基地接任务（NPC）→ 出舱低重力行走 → 驾驶月球车越野（小地图导航）→ 到达勘测点完成采样/探测互动 → 携样本返回基地交付 → 解锁下一段**

具体任务链（5 个主线任务，附 2 个支线彩蛋）：

| # | 任务名 | 内容 | 用到的系统 |
|---|---|---|---|
| 1 | 重返月面 | 出舱，低重力行走教学（6 倍跳跃高度），走到月球车 | 行走控制、低重力 |
| 2 | 越野巡航 | 驾驶月球车前往 3 号陨石坑勘测点，途中地形起伏、岩石避障 | 载具控制、小地图 |
| 3 | 采样作业 | 在勘测点用钻取/铲取互动采集月壤样本×3（按住 E 进度条） | 交互系统、任务系统 |
| 4 | 极地寻冰 | 驾车前往永久阴影坑，探测水冰信号（探测器 UI 峰值引导） | 小地图、音效引导 |
| 5 | 荣归 | 返回基地，将样本移交科学家 NPC，参观**展览舱**：微缩模型 + 介绍页面 + 二维码，手机扫码后呈现对应 AR 模型（虚实结合核心场景） | NPC、展览台交互、AR 场景 |

- 支线彩蛋：月面放置"嫦娥四号/玉兔二号"模型，靠近弹出真实科普卡片；找到隐藏的"月球车脚印"成就。

### 第四幕 · 回（返回地球，约 2 分钟）
- 演出：样本装入上升器 → 上升器发射（月面视角倒退镜头）→ 交会对接 → 再入大气层隔热炫光 → 开伞 → 着陆场草原。
- 结算画面：任务用时、样本数、成就 + **真实探月大事记时间线**（2007 嫦娥一号 … 2020 嫦娥五号采样返回 1731 克 … 2024 嫦娥六号月背采样），完成教育闭环。

## 三、场景与美术设计

### 3.1 场景清单（5 个 Unity Scene）

| 场景 | 内容体量 | 美术要点 |
|---|---|---|
| S1 发射场 | 指挥中心内景 + 发射塔架 + 火箭 + 观景平台 | 傍晚暖光，体积雾，发射时强点光源 |
| S2 太空/轨道 | 指令舱内景 + 舷窗 + 地球/月球/太阳天体 | 星空 Skybox，地球自转材质 |
| S3 着陆下降 | 着陆器视角 + 月面（高空→地表） | 月面渐近，引擎扬尘粒子 |
| S4 月面基地（核心） | 广寒站 3 舱段 + 太阳能板阵列 + 通讯天线 + 展览舱（微缩展品与介绍页面）+ 周边地形（陨石坑、岩石区、永久阴影坑）+ 停月球车 | 冷色低角度"太阳光"+ 黑色天空 + 地球悬在天上；地形起伏要支持驾驶乐趣 |
| S5 返回与结算 | 上升器发射 + 再入 + 着陆场 + 结算 UI | 隔热等离子光效、开伞 |
| S6 AR 场景（手机端） | 摄像头取景 + 二维码识别 + 平面检测 + 模型放置与数据卡 | 安卓/iOS 构建，与 PC 端共用同一 Unity 工程 |

> S2/S3 可以合并为"飞行段"一个场景，用 Timeline 分段，降低工作量。

### 3.2 模型与素材来源策略
- **自建（Blender）**：月球车（六轮、太阳能板、座椅——驾驶舱视角资产）、月球基地舱段（圆柱舱+对接节点）、着陆器。低模 + 法线贴图即可，风格统一比精度重要。
- **免费素材（Asset Store / Sketchfab CC0 / NASA 3D 资源库）**：火箭、发射塔、宇航员、岩石、陨石坑笔刷、月面贴图、星空 HDRI。
- **虚实结合素材**：嫦娥任务真实照片/影像（国家航天局、新华社公开报道图）、真实月面高清照片（NASA LRO/嫦娥二号公布图）用于地形纹理与展览台介绍页面，附来源与授权说明表；AR 场景展示的模型复用模块二自建资产。

### 3.3 后期
- 全局：Bloom（引擎喷焰、太阳）、暗角、色彩分级（月面段降低饱和度、提高对比）。
- 性能红线：GTX 1650 级别笔记本 60 FPS，Drawcall < 300，灯光 ≤ 3 实时光/场景。

## 四、系统设计（程序模块）

### 4.1 脚本清单（约 17~22 个脚本，模块一交付物）

```
/Scripts
 ├─ Player
 │   ├─ FirstPersonController.cs      // 步行：WASD+鼠标，低重力参数化（重力系数可调 1.62/9.8）
 │   └─ PlayerInteractor.cs           // E 键射线交互，进度条采样
 ├─ Vehicle
 │   ├─ RoverController.cs            // 核心：←→转向(视线方向)、↑↓速度(油门刹车)、Shift加速、空格手刹
 │   └─ RoverCamera.cs               // 追尾相机，速度越快 FOV 越大
 ├─ UI
 │   ├─ MinimapController.cs          // 正交相机俯拍 + RenderTexture，玩家箭头/任务图标旋转
 │   ├─ HUDController.cs             // 速度表、氧气（氛围值）、任务提示、真实数据条
 │   └─ DialogueUI.cs                // NPC 对话框，打字机效果
 ├─ NPC
 │   ├─ NPCAgent.cs                  // NavMesh 巡逻/待机/面向玩家
 │   └─ DialogueTrigger.cs           // 对话数据(ScriptableObject)触发
 ├─ Quest
 │   ├─ QuestManager.cs              // 主线任务状态机（未接/进行/可交付/完成）
 │   ├─ QuestData.cs                 // ScriptableObject：任务描述/目标/奖励
 │   └─ QuestMarker.cs               // 任务点世界图标 + 小地图图标联动
 ├─ Cinematic
 │   ├─ LaunchSequence.cs            // 发射序列编排（倒计时/震屏/音量/切换镜头）
 │   ├─ LandingMinigame.cs           // 着陆小游戏：推力/水平速度/着陆判定
 │   └─ SceneFader.cs               // 黑场转场 + 真实影像播放
 ├─ Audio
 │   ├─ AudioManager.cs              // 全局 BGM/环境音切换（场景驱动）
 │   └─ RadioVoice.cs               // 飞控语音队列（字幕同步）
 ├─ AR（手机端）
 │   ├─ ARSceneManager.cs           // AR 会话管理 + 二维码识别（ZXing）选择模型
 │   └─ ARModelPlacer.cs            // 平面检测、点击放置、旋转缩放、数据卡 UI
 └─ Misc
     ├─ InteractableBase.cs          // 交互物基类（样本/舱门/科普展板）
     └─ AchievementSystem.cs         // 成就（彩蛋）
```

### 4.2 关键实现要点
- **小地图**：月面场景放一个正交相机（俯视，跟随玩家），输出到 RenderTexture 贴在 HUD RawImage 上；玩家箭头用单独 UI Image 按朝向旋转，任务点通过 `RectTransformUtility.WorldToScreenPoint` 换算到小地图坐标。M 键切换大小两种比例。
- **月球车手感**：不使用 WheelCollider 物理车轮（调参复杂、稳定性差），采用**刚体 + 自定义轮胎力简化模型**：速度、转向两个标量，转向随速度衰减（高速转向变钝，形成越野感），地形坡度通过射线检测取法线做俯仰侧倾视觉。以百行以内的代码实现稳定的越野驾驶手感。
- **NPC**：NavMeshAgent 巡逻 + 面向玩家触发对话；对话内容全部抽成 ScriptableObject 数据资产，改台词不用碰代码（模块三直接填表）。
- **任务系统**：事件驱动（`OnSampleCollected` 等），UI 与逻辑解耦，任务链配置化。
- **AR 虚实结合**：触发采用"二维码识别 + 平面检测放置"的组合——二维码是对单帧图像的解码，从屏幕识别可靠（避开屏幕图像连续追踪的不稳定问题）；二维码内嵌于展览台介绍页面 UI，编码对应模型编号；PC 主线与手机 AR 为同一 Unity 工程的两个场景，分别构建 PC 版 exe 与安卓 APK。
- **过场**：Timeline + Cinemachine（免费包），发射/对接/再入三段大演出用它编排，组装工作以"拖拽+调时间轴"为主，配图文步骤即可上手。

### 4.3 音频清单（模块四负责收集与接入）
- BGM 3 段：地球（管弦希望感）/ 太空（氛围电子）/ 月面（孤独简约）。
- 音效：火箭轰鸣、舱内提示音、无线电杂音、月面静电噪声、脚步（月壤闷响）、车轮扬尘、采样钻机、UI 点击。
- 飞控语音：可由 TTS 生成普通话女声，或由组员配音（后者效果更佳）。

## 五、技术方案

- **引擎**：Unity 6 LTS（6000.x，为满足 AR Foundation 6.x 的版本要求；工程尚未创建，无迁移成本），URP 渲染管线（方便后期调色）。
- **AR**：AR Foundation 6 + XR Plug-in Management（ARCore/ARKit 插件），二维码识别用 ZXing；安装 Unity 时需勾选 Android Build Support。设备要求：全组至少一台支持 AR 的手机（安卓需 ARCore 认证机型，iPhone 均可）。
- **语言**：C#。
- **版本管理**：Git + GitHub 私有仓库。Unity 加 `.gitignore` + `Edit > Project Settings > Editor > Asset Serialization: Force Text`。
- **协作方式**：场景文件直接合并的冲突风险高，因此**按目录分工**：`/Scripts` 与 UI 逻辑归模块一，`/Scenes` 与 `/Art` 归模块二，`/Content`（对话、素材表）归模块三，`/Cinematics` 与 `/Audio` 归模块四；同一场景不同人修改前先在群里报备。

## 六、团队分工：四大工作模块

> 项目工作划分为四个平行模块，**第一次组会现场认领**：每人主导一个、对交付物负责，第 12 周每人汇报的内容就是自己模块的产出。四个模块没有主次之分，均为项目的必要组成部分；模块之间设有协作点，可互相支援（协助内容计入个人汇报）。
> 每个模块都配有模板、素材清单或图文步骤，认领时按个人兴趣选择即可。

### 模块一「引擎室」· 交互与系统 —— 让一切动起来

**做什么**
- 步行与低重力控制（月面 1/6 重力的跳跃手感）
- 月球车驾驶系统：←→ 转向、↑↓ 油门刹车、Shift 加速、空格手刹（课程核心要求）
- HUD 小地图、任务系统与 NPC 对话逻辑框架
- 手机端 AR 场景：二维码识别、平面检测放置、模型交互（AR Foundation）
- 全流程集成与测试：场景串联、Bug 修复、性能优化、PC 端 exe 与安卓 APK 打包、测试用例与逐版本回归

**交付物**：全套控制与系统脚本（约 17~22 个）、可玩驾驶 demo、手机端 AR 场景、测试记录、可交付 Build 版本（PC + 安卓）

**适合**：喜欢研究操作手感、拆解游戏逻辑、不排斥写代码的同学

**上手支持**：控制脚本骨架与挂载说明、测试用例模板已备好

### 模块二「造景司」· 场景与美术 —— 把月球造出来

**做什么**
- Blender 建模：月球车、基地舱段、着陆器（低模 + 贴图，风格统一）
- 月面地形雕刻：陨石坑、岩石散布、永久阴影坑（驾驶乐趣的地形基础）
- 五个场景的美术搭建与整合：发射场（塔架/火箭/指挥中心）、太空舱内景、月面基地（含展览舱与展览台造景、微缩展品）
- 灯光与后期：月面冷色低角度光、黑色天空、悬空的地球、Bloom 与调色

**交付物**：3 组自建模型、S1~S5 场景美术、灯光后期配置、美术风格设定集

**适合**：喜欢建模、搭场景、调光影的同学

**上手支持**：免费素材包清单（火箭/宇航员/岩石/贴图）、参考图与面数规范已备好

### 模块三「叙事局」· 剧本与内容 —— 讲一个好故事

**做什么**
- 剧本创作：五幕分镜脚本、5 个主线任务 + 2 个支线彩蛋的完整设计
- 全部 NPC 人设与台词（飞控、指挥官、科学家）、飞控语音广播稿
- 虚实结合内容：收集真实影像/照片/数据并整理来源授权表；展览台介绍页面文案与 AR 数据卡、结算页大事记编排
- 操作使用手册；对话数据填入 Unity（填表式，不写代码）与展览台摆放

**交付物**：剧本文档、素材包与来源表、展览台介绍页面与数据卡、操作手册

**适合**：喜欢写故事、查资料、做内容策划的同学

**上手支持**：剧本分镜模板、素材来源清单、对话填表说明已备好

### 模块四「片场组」· 演出与视听 —— 让体验有电影感

**做什么**
- 三段大演出组装（Timeline + Cinemachine，拖拽时间轴为主）：火箭发射序列、绕月"地出"镜头、返回段再入与开伞
- 着陆小游戏的参数调试（调数值，不写代码）
- HUD 与对话框的界面拼装（UGUI 拖拽布局、图标配图）
- 音频与影像：BGM/音效收集剪辑、场景音源布置、飞控语音对轨；演示视频的脚本、录制与剪辑（含手机 AR 段落录屏）

**交付物**：三段演出、HUD 界面、音频资源包、3~5 分钟演示视频

**适合**：喜欢剪辑、配乐、镜头与演出效果的同学
