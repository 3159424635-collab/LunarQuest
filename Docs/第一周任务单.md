# 第一周任务单（环境搭建与模块熟悉）

> 目标：全员完成环境搭建，熟悉各自模块的范围与交付要求。本周不要求产出正式内容。
> 本周结束时，每人应能回答三个问题：我的模块做什么、交付什么、第一步从哪里开始。

## 全员（周一至周二完成）

1. 接受 GitHub 仓库邀请（邮箱链接或 github.com 右上角通知），安装 GitHub Desktop（desktop.github.com），克隆仓库
2. 安装 Unity Hub 与 **Unity 2022.3.62f1**（版本必须一致；本机已有其他版本的不用卸载，另装此版本）
3. 查询自己手机是否支持 AR：安卓在搜索引擎搜 "ARCore supported devices" 进入谷歌官方列表核对型号；iPhone 无需查询。结果发群（至少需要一台可用设备）
4. 通读仓库 `Docs/月征-探月VR项目方案书.md` 中与自己模块相关的章节

## 模块一 · 交互与系统

- 按仓库 README 流程建立 Unity 工程并合入仓库
- 跑通 `Docs/模块一-脚本挂载说明.md` 的白盒验收清单
- 逐个通读 `Assets/_Project/Scripts` 下的脚本，目标：能说清每个脚本的输入、输出与挂载方式
- 本周产出：白盒场景可运行，验收清单逐条结果记录

## 模块二 · 场景与美术

- 安装 Blender（blender.org，4.x 版本）
- 收集参考图 20 张（月球基地、月球车、着陆器、月面地形各 5 张），打包发群，文件名注明分类
- 从 Sketchfab 下载一个免费月球车模型，按 `Docs/规范-模型交付规范.md` 逐条对照检查（比例、原点、朝向、命名），记录检查结果
- 本周产出：参考图集 + 一份规范自查记录

## 模块三 · 剧本与内容

- 按 `Docs/模板包/模板-剧本分镜.md` 写序幕（地球发射场）分镜初稿，约 10 个镜头
- 按 `Docs/模板包/模板-素材来源与授权.md` 开始收集真实素材，本周入库 10 条（每条附来源与授权说明）
- 本周产出：序幕分镜 v0 + 素材表前 10 条

## 模块四 · 演出与视听

- 在 Unity Learn（learn.unity.com）搜索 "Timeline"，完成入门教程并记录要点
- 按 `Docs/模板包/模板-CC0音源清单.md` 收集音效，本周入库 5 条（对应清单中的具体需求项）
- 本周产出：音效 5 条（按模板规范命名）+ Timeline 学习笔记半页
