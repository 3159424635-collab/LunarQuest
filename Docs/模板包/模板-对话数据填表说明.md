# 模板 · 对话数据填表说明（模块三用）

> 对话内容以填表方式录入 Unity，不接触代码。字段结构以模块一最终实现的 ScriptableObject 为准，
> 如有调整会在群里同步更新本说明。

## 字段说明

| 字段 | 含义 | 填写要求 |
|---|---|---|
| 对话ID | 唯一编号 | 按 `D001` 递增 |
| 所属NPC | 说话人 | 飞控 / 指挥官 / 科学家（与方案书人设一致） |
| 台词正文 | 对话内容 | 每句一行；口语化、符合人设；单句不超过 30 字为宜 |
| 触发条件 | 何时播放 | 如：靠近 3 米 / 任务接取时 / 任务交付时 |
| 结束动作 | 播完后发生什么 | 无 / 接任务 / 完成任务 / 播放演出 / 打开介绍页 |

## 填写示例

| 对话ID | 所属NPC | 台词正文 | 触发条件 | 结束动作 |
|---|---|---|---|---|
| D001 | 飞控 | 各系统自检完成。| 序幕开始 | 无 |
| D002 | 飞控 | 请前往观景平台。| D001 结束 | 任务简报 UI |
| D101 | 指挥官 | 样本就位，准备出舱。| 任务Q1接取 | 无 |

## 人设速记（写台词时对齐）

- **飞控**（地面）：专业、简洁，播报式语气
- **指挥官**（基地）：沉稳、指令式，负责发任务
- **科学家**（基地）：热情、科普感，负责介绍与交付
